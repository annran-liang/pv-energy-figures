# 配色：先定语义，再挑颜色

## 从参考论文中观察到的方式

- **P02**：同一效益的地图、边际曲线与统计图以近似同色系联系；不同指标切换紫、绿、蓝等主色。可借鉴面板间语义一致性，不照搬其多色连续色带。
- **P04、P20**：用不同单色系区分潜力/指标，用少量类别色连接分组与地图。
- **P07、P10、P13**：通过情景/年代颜色和分面建立可比性；区间与中心线使用同色淡化。
- **P09、P19**：城乡或能源类别颜色在组成、分布和分配表达中延续。
- **P15、P17、P18**：可行域、成本/备用收益和两类结局各有编码，细边线与浅填充避免抢占数据。

以下 HEX 为本 skill 的设计建议；没有从原 PDF 精确抽样。不是期刊官方色板，也未通过色觉缺陷仿真认证。建议结合点型、线型和直接标签复核辨认性。

## 编码决策

1. **无序类别**：使用离散色；不以从浅到深暗示高低。多数情况下3–5类足够，更多类优先分面/灰底重点突出。
2. **有序强度**：顺序色；最低色仍应区别于白色海洋/背景。绝对零值、缺失和不适用三者要分开。
3. **有符号差值**：发散色，以有意义的零或基准为中心。若中心不为0，写明含义。只有科学含义合理时才采用对称范围。
4. **时间/情景两维同时出现**：优先颜色表示情景、横轴表示时间；不要用两套颜色同时表示年代和情景。
5. **多指标与情景冲突**：不同指标分面，沿用情景色；若主图是指标地图，则指标用各自单色，情景改为列。
6. **同一类别跨图一致**：持久化 `scenario_to_color` 或 `group_to_color` 字典，不能依赖排序后自动颜色循环。

## 地图和热图

- 同一指标的年份/方案比较，优先共同区间；若采用分位数分箱，一组地图使用同一组实际边界，不能每幅重分位后直接比较强度。
- 极端值使主体不可读时，可考虑对数、分段/分位色标或裁剪；明确变换、阈值和超界端帽。log 不适用于0或负数，不能静默加常数。
- 双变量地图用清楚的二维图例，通常3×3；必须定义每轴分箱、方向与缺失处理。不可简单混合两套顺序色，便声称九类都可区分。
- 置信度/显著性与效应量分开编码；点描可能遮挡细城市边界，密度应克制。没有显著性检验数据时不能加点描。
- 纬向/经向统计、地图色条、分布坐标需对应同一数据与单位。不要把总量地图旁的纬带均值误标为总量。

## 线、点、带和文字

中心线保持可辨，区间带可先试 alpha 0.12–0.22。两条曲线接近时加线型或末端标签；主要比较超过5条时考虑分面。文字用深色，浅色只用于大面积填充。不要用颜色深浅替代没有数值依据的不确定性。

色觉/灰度审查是对最终图的检查，不是对 HEX 列表的口头保证。检查主要比较是否仍能凭线型、点型、标签、位置辨认。
