# 与研究问题对应的组合

尺寸比例是起点，不是期刊规定。a/b/c 代表阅读顺序，可以随论证调整。每幅主图保留一句可被数据检验的主张；通常选3–5个必要面板，复杂地图组允许更多，但须保证成稿尺寸可读。

## L1 潜力在哪里、重点地区是否一致

适用：城市屋顶光伏、立面潜力、部署优先级。参考 P04 F5–6、P02 F1。

```
┌──────────────┬────────┐
│ a 主地图 60%  │ b 分布 │
├──────────────┴────────┤
│ c 城市/群体排序 + 少量重点标签 │
└───────────────────────┘
```

地图解释空间聚集；分布解释长尾；排序解释优先级。若重点是地理集中度，可把 b 换为经纬度边际统计。总量与强度应分两图或两行，不用双轴强行拼合。

## L2 气候如何改变未来光伏价值

适用：气候影响、装机与发电、成本/收益情景。参考 P07 F1–5、P10 F4–5、P06 F2–4。

```
┌────────────────────────┐
│ a 情景趋势 + 定义清楚的区间带 │
├────────┬────────┬──────┤
│ b 2030 │ c 2050 │ d 群体 │
│ Δ地图  │ Δ地图  │ 分布   │
└────────┴────────┴──────┘
```

趋势回答何时变化，地图回答何处变化，分布回答谁偏离平均。两幅变化地图在同变量同单位时共享以0为中心的色标；绝对基线地图单独使用顺序色标。研究主结论若是空间反转，让地图成为主面板。

## L3 碳—水—土地协同与权衡

适用：多效益、生命周期、技术/经济优先级。参考 P10 F3、F5。

```
┌─────────┬─────────┬─────────┐
│ a Δ碳   │ b Δ水   │ c Δ土地 │
├─────────┴─────────┼─────────┤
│ d 收益权衡/效率散点 │ e 排名流动│
└───────────────────┴─────────┘
```

不同单位不能共用数值色条。每项指标的地图与趋势可采用对应单色，但同一散点里优先让颜色表示区域/情景，指标用坐标轴。若只有三个国家或城市，直接用分面点图；不要为布局填充地图。综合指数需报告方向、标准化、权重与敏感性。

## L4 光伏是否减轻能源负担、是否公平

适用：低收入家庭、融资、电价改革。参考 P14 F1–7、P17 F3–8、P09 F3–5。

```
┌──────────────┬──────────────┐
│ a 分组分布/配对变化 │ b 阈值覆盖率   │
├──────────────┼──────────────┤
│ c 集中/分配曲线    │ d 分组效应与区间│
└──────────────┴──────────────┘
```

样本量和加权方式在图注里明确。负担阈值应来自研究定义，不能默认6%适用于所有国家。货币节省最多的家庭不一定负担下降最大；需要时把美元/户与百分点拆开。只有描述性模拟时，d 用模拟差值区间，不能伪装成回归系数。

## L5 可靠性、成本与搁浅资产的边界

适用：光储、微电网、供需匹配。参考 P15 F2–5、P11 F1–4。

```
┌────────────┬────────────┐
│ a 成本参数热图│ b 排放/可靠性│
├────────────┼────────────┤
│ c 边界/阈值  │ d 日内或极端周│
└────────────┴────────────┘
```

热图坐标完全对应；不可行方案标为空白/斜线并给图例。d 选择极端事件应有规则，不能仅选最漂亮的一周。容量 kW、能量 kWh、备用小时和负荷覆盖率分别标注。

## L6 冲击或技术采用怎样影响行为

适用：停电对电动车采用、热泵舒适反弹、能源转型公平。参考 P16 F1–3、P18 F1–6、P03 F4–5。

```
┌────────────┬────────────┐
│ a 暴露/描述   │ b 主效应区间  │
├────────────┴────────────┤
│ c 预设异质性 + 关键稳健性/边界 │
└─────────────────────────┘
```

有识别设计时可用事件研究替换 a/b，标为扩展建议。系数不同单位或不同标准化时拆轴。不要将模型重要性图置于“机制证据”位置，除非有额外研究设计支持。

## L7 技术组成、系统转型与流向

适用：排放核算、能源路径、电力互联。参考 P01 F2–4、P12 F2–3、P13 F3–5。

```
┌────────────────────────┐
│ a 各情景技术组成的可比小多图 │
├────────────┬────────────┤
│ b 来源/去向流图│ c 净变化与代价│
└────────────┴────────────┘
```

组成用真实可加总量；技术颜色与层次次序固定。Sankey 只用于确有来源—去向关系的数据。多色电网图过密时高亮重点通道，余者灰色；完整矩阵进补充材料。

## L8 规模化估计如何获得可信结果

适用：遥感识别屋顶、建筑尺度模型、机器学习估计。参考 P04 F2–3、P10 F1、P14 F8。

```
┌────────────┬────────────┐
│ a 数据→模型简图│ b 局部识别示例│
├────────────┼────────────┤
│ c 观测 vs 预测│ d 残差/误差分布│
└────────────┴────────────┘
```

验证必须采用真实留出/交叉验证结果；1:1参考线不等于拟合线。报告区域/时间外推边界，不能只展示高 R²。对长尾城市显示相对误差与绝对误差的差别。

## L9 从技术潜力到实际可部署优先序

适用：技术潜力、用电匹配与政策约束造成部署缺口。参考 P20 F1–5。

```
┌────────────┬────────────┐
│ a 技术/可部署差异│ b 约束或类型分布│
├────────────┴────────────┤
│ c 容量加权的经济/减碳排序曲线 │
├─────────────────────────┤
│ d 目标年份部署路径地图或点图  │
└─────────────────────────┘
```

技术潜力、经济潜力、可部署潜力分别定义。排序曲线用容量作为宽度，收益作为高度；经济优先与减碳优先应是可比但独立的两条路径。目标年份不能只凭画面插值，要来自真实部署规则与约束。

## 整篇论文的图序

可从“研究系统与数据可信度 → 核心空间/总体结果 → 群体或多效益错位 → 未来情景 → 约束与政策边界”中选必要环节。根据论文的新贡献调整顺序和数量。方法图不是必有 Fig.1，稳健性不是一律放补充材料；会改变主结论的反例必须可见。

## 压缩与对齐

若主文空间有限，保留地图/趋势中最有信息的一项，再加分布或比较面板；把同口径的展开地图放补充材料。图外边框对齐不代表绘图区对齐：检查相同组的实际轴框宽高、坐标基线和间距。主面板可跨行/跨列，其余比较组内部保持一致；地图保持合理纵横比，不拉伸填格。
