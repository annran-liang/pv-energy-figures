# 绘制方式与成稿检查

## 数据与实现

优先继续用户现有代码和环境。Python 常见组合：matplotlib 的 GridSpec/subplots + pandas；空间图用 geopandas/cartopy，前提是实际可用。R 可用 ggplot2 + patchwork + sf；空间权重、分布和不确定性计算由研究定义决定。工具不可用时先说明并使用等价可行方案，不能虚报已绘制或已测试。

为复用保留长表：

| 任务 | 建议字段 | 核对重点 |
|---|---|---|
| 城市空间/潜力 | `region_id, year, scenario, metric, value, unit` + 几何连接键 | 不同来源地区 ID 和边界时间是否一致 |
| 情景趋势 | `year, scenario, metric, estimate, lower, upper, interval_type` | 区间是否来自真实模型/抽样；上下界同量纲 |
| 家庭分配 | `household_id, group, condition, income, cost, outcome, weight` | 分母、权重、配对、缺失与负值 |
| 回归/异质性 | `model, group, term, estimate, lower, upper, interval_type, n` | 区间置信水平、基准组、标准化、是否聚类 |
| 光储可行域 | `pv_kw, battery_kwh, reliability, lcue, emissions, feasible` | 容量/能量单位、不可行方案、可靠性定义 |
| 技术流向 | `source, target, stage, scenario, value, unit` | 节点守恒/损耗、容量与电量区别 |

使用数据实际列名，不强制重命名用户文件。先检查数据结构再画图，不自动重估模型、改样本或剔除离群值。

## 布局和线条

- 以最终物理尺寸设计。无期刊规定时可先试85–90 mm单栏、175–180 mm双栏；它们是工作尺寸，不能称为目标期刊的硬性规定。
- 正文/轴标题可先试8–9 pt，刻度/图例7–8 pt；面板字母9–10 pt加粗。根据语言、图密度与目标要求调整。中文使用已安装且可嵌入的中文字体；不能只设 Arial 后忽略缺字。
- 数据线约1.0–1.5 pt、轴线0.5–0.7 pt、边界线更浅；比较组内部统一。细城市边界不应压过填色。
- 柱/条表示绝对量通常从0起；线/点图可缩窄范围但标注充分。比例0–1与百分比0–100一致转换；负担变化的%与百分点明确区分。
- 分布类图不把箱须解释为CI，注明箱体/须定义。对统计小提琴保留样本支持，不能画出物理上不可能的负能耗。
- 排序曲线用真实 x 宽度：边际供给曲线的柱宽表示容量；不要把每个城市画等宽后仍将横轴标成累计容量。
- 主图例集中，局部例外在对应面板说明。先减少不必要图例，再缩字号。小多图共享轴时要保留足够单位和范围信息。

## 地图和边际统计

地图使用适合地理范围和用途的投影，面积相关比较应考虑等积投影。不要把未投影经纬度面积直接当作土地面积。中国地区边界、插图和范围以用户合法数据和投稿要求为准，不能凭空补画行政区。为所有地图保留边界来源、CRS、连接匹配率与缺失记录。

统计经纬度边际量时，先定义是容量求和、面积加权强度还是人口加权暴露。地图单元的总量不能再次乘面积；强度汇总要检查分母。

## 颜色应用

`figure_style.py` 不导入绘图库，可在纯标准库环境中导出代码与参数。输出 Python 示例需在有 matplotlib 的环境执行；R 示例需 ggplot2。调用输出是起点，不能证明数据图已经通过检查。

```text
python scripts/figure_style.py --palette household-pair --format python
python scripts/figure_style.py --palette change-div --format r
python scripts/figure_style.py --preview palette-preview.svg
```

顺序色插值用于连续变量，离散色用于类别；不能直接把离散情景色插值成强度热图。发散变量采用明确的中心归一化，而非只选择蓝红色带。

## 渲染与交付

1. 导出并查看完整图，再检查每个面板与最终物理尺寸。地图/热图中的密集栅格层可栅格化，文字、坐标和线条尽量保留为矢量。
2. 对比实际绘图区、面板字母位置、坐标范围、色标、图例与单位；检查溢出、遮挡、灰度辨认与中文缺字。
3. 核对图中关键数字、阈值覆盖率、正负号与图注。可用导出的汇总表验证；原数据和程序应可追溯。
4. 交付可编辑绘图源代码、最终 PDF/SVG（适合的格式）和 PNG 预览；需要复现时附数据列映射及运行说明。无指定要求时，位图预览可用300 dpi，不能用提高dpi代替文字/布局修复。
5. 图注包含分析对象、条件、单位、样本量/权重、区间和关键阈值；别把推测写成数据事实。精确投稿要求查对应期刊当前官方说明。

如果未渲染或部分依赖无法验证，在交付时说明实际检查范围；不能说“投稿级”“检查全通过”来代替证据。
