# 光伏与能源科研作图

把研究问题转换为清楚、可信、可复现的图。重点帮助用户发现更合适的图型和组合，而非仅给已有柱状图换色。默认中文讨论；图内语言沿用稿件或用户要求。

## 按任务读取

- **不知道选什么图、想增加选择**：读 [图型库](references/chart-atlas.md)，再按主题查 [论文图谱](references/paper-library.md)。
- **一张主图或整篇论文组图**：读 [组合方案](references/compositions.md)。
- **颜色、地图色标或整篇统一视觉**：读 [配色规则](references/color-system.md)，使用 [可读取色库](assets/palettes.json)。
- **真正绘制、修改代码、交付文件**：再读 [绘制与检查](references/drawing-guide.md)。
- **用户要求新增参考论文**：按 [参考库维护](references/maintenance.md) 更新证据，不能仅据标题推测图型。

这些文件可独立使用，不依赖 nature-figure 或外部脚本。参考论文是视觉经验来源，不能代表期刊正式要求。

想直观比较常用表达时查看 [原创示例图册](assets/figure-gallery.png) 和 [配色色卡](assets/palette-preview.svg)。图册使用模拟数据，仅说明图型；生成脚本为 `scripts/render_gallery.py`，需 numpy/matplotlib，不依赖原始论文文件。

## 从问题到方案

1. 从已有材料提取：拟支持的结论、比较对象、分析尺度、数据字段、时间/情景、样本和不确定性、稿件语言及输出用途。已经能推断的内容不重复询问。仅当缺失项会改变科学含义或阻止绘制时，问最关键的问题，并继续可独立完成的设计。
2. 先写一句“这幅图要让读者看懂什么”。如果只是探索，写待检验的问题，不能预设结果方向。
3. 选择图型，通常给 **3 个有实质差别的方案**：最适合主结论的方案、能揭示异质性或机制的方案、适合主文空间受限的精简方案。明确推荐项；窄小修改或用户已选定图型时直接执行，不强行列三案。
4. 每个方案写清：图型/组合、能支持的结论、面板顺序、所需数据、编码方式、配色 ID 与关键色号、局限、参考论文 ID + 图号 + PDF 页码。具体图型未在库中出现时，可以推荐，但标为“扩展建议”，不能虚构论文出处。
5. 组合按读者推理顺序组织：哪里/多大 → 谁受益或受损 → 为什么/受什么约束 → 哪些情景下仍成立。仅使用论证需要的环节，不固定面板数量。避免把所有可用指标挤进一张图。
6. 做颜色语义表并全篇沿用。一个颜色优先承载一个含义；情景、技术、收入组、效益指标冲突时，用分面、线型、点型拆分编码。
7. 用户只要建议时，交付可执行的设计方案。用户要求画图时，继续完成代码、渲染、视觉检查和文件交付；不在方案阶段再次索要开始许可。沿用现有 Python/R/其他科研工作流；没有既定工具时可选本地可用且适合任务的工具并说明理由。

## 领域重点

- **屋顶/立面光伏潜力**：地图 + 分布/排序；区分技术、可部署、经济潜力，面积、装机、发电不可混用。
- **未来气候与光伏价值**：情景曲线 + 不确定性带 + 时间切片变化地图；区分基线水平与相对变化。
- **能源—碳—水—土地效益**：不同单位分面；排名流动或权衡散点帮助识别错位，不能把归一化面积当作可加总福利。
- **家庭能源负担/公平**：分组分布 + 阈值 + 分配曲线；区分货币节省、百分比变化与百分点变化，并给出分母和权重。
- **可靠性/储能**：参数热图 + 可行边界 + 运行剖面/持续曲线；年均发电平衡不能替代逐时可靠性。
- **计量结果/反弹效应**：系数区间图、事件研究或分组效应；区分描述性相关、模型解释与因果识别。

## 科学与视觉底线

- 没有数据时可出布局线框或示例代码；示例数值必须显著标注“模拟数据，仅用于版式演示”，不能写成真实发现。
- 地图的投影、边界版本、空间单元、面积/人口权重、缺失区域与色标阈值要明确；只比较相同量和单位时共享色标。
- 区间带注明 CI、SD、IQR、模型范围或分位数；不把不同定义互换。主文不能隐藏会推翻结论的情景或群体。
- 不因参考论文用了雷达图、环图、多彩网络或双轴，就默认照搬。先说明它比点图、热图、条形图多回答了什么。
- 模型变量重要性、SHAP、部分依赖和相关散点不能自动解释为因果贡献。
- 参考库中的配色观察是视觉概括；推荐 HEX 是重新设计的色库，并非逐像素提取或经色觉无障碍认证。
- 不复制论文图中的数值、地图和绘图作品作为用户新结果。学习组织方式，用用户数据重新绘制。新数据与结论优先于参考外观。
- 不声称统一的“Nature 官方风格”。只有明确目标期刊、投稿阶段且需要精确规格时，才查当时官方指南。

## 建议输出格式

先给推荐结论，再用简洁对照表列候选：

| 方案 | 科学问题/优势 | 图型与面板顺序 | 数据条件 | 配色 | 参考与局限 |
|---|---|---|---|---|---|

对推荐方案补充：a/b/c 各面板职责、相对面积、共享坐标/图例、颜色语义、必要标注，以及下一步能直接使用的数据字段或代码。用户选定方案后减少重复解释。

可用调用例：

- `$pv-energy-figures 我有中国城市屋顶光伏、减碳、水和土地效益，推荐三种主图组合并说明配色。`
- `$pv-energy-figures 比较未来情景中低收入家庭的能源负担，给我比均值柱状图更好的选择。`
- `$pv-energy-figures 按参考库帮我审查这张图的图型、颜色语义与面板顺序，并修改绘图代码。`

需要色号或 Python 风格参数时运行 `python scripts/figure_style.py --palette scenario --format json`；支持 `--format python`、`--format r`，以及 `--preview 输出.svg`。脚本自身只依赖 Python 标准库。
